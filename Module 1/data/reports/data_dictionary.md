## Target Variables

### `late_delivery_risk`

Binary classification target:

- `0` = No late-delivery risk
- `1` = Late-delivery risk

### `delay_duration_days`

Regression target representing the number of days a shipment is delayed.

- `0` = No shipping delay
- Positive value = Number of delayed days

## Data Leakage Note

Historical outcome fields are retained in the master dataset for analysis and future evaluation.

They must be excluded from predictive model inputs when they reveal information that would only be known after the shipment outcome.

Examples include:

- `delivery_status`
- `shipping_date_dateorders`
- `days_for_shipping_real`
- `shipping_delay_days`
- `delay_duration_days`
